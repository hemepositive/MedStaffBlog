This tip sheet walks through the full discharge workflow, including how to fill out post-acute care orders for patients going to assisted living, a skilled nursing facility (SNF), home health or home with DME.

<div class="key-message">

Work down the Discharge page until every **red asterisk (\*)** section shows a **green check mark**. For any discharge to a facility, you also need a signed discharge summary and a signed discharge med list.

</div>

## 1. Open the Discharge page

Select the **Discharge** tab from Provider View. The red-asterisk sections on the left (Order Profile, Home Medications, Patient Education and Follow Up) are the ones you need to complete.

![The Provider View with the Discharge tab highlighted and the Problem List open, showing red asterisks beside Order Profile, Home Medications, Patient Education and Follow Up](/images/post-acute-care-orders/page-01.png)

## 2. Update the problem list and open the order profile

Update the Problem List first. Then open **Order Profile**, review it, and place the discharge order set **HOSP Discharge Orders**. Make sure to complete all related discharge orders.

![The Problem List with This Visit and Chronic buttons, and the Order Profile link highlighted below it](/images/post-acute-care-orders/page-02.png)

## 3. Find the HOSP Discharge Orders set

You can select the order set from the Orders page, or search for it with **+ Add** next to Orders in the table of contents. Searching "hosp disc orders" shows **HOSP Discharge Orders**. Choose that one rather than the ORTHO discharge set.

![The PowerPlans list with HOSP Discharge Orders highlighted, and the Orders + Add search showing HOSP Discharge Orders in the results](/images/post-acute-care-orders/page-03.png)

## 4. Work through the order set

The order set groups discharge orders by section: Admit/Transfer/Discharge/Status, Patient Care, line and tube discontinuation, Activity, diagnostic tests, therapies and communication orders.

- Under **Admit/Transfer/Discharge/Status**, select the sub-order-set that matches where the patient is going: **HOSP Assisted Living**, **HOSP Home Health**, **HOSP Skilled Nursing (SNF)** or **HOSP DME Orders**.
- Complete the Post Discharge orders that apply, such as diet instruction and activity restrictions.

![The HOSP Discharge Orders plan with the check boxes down the left, the four destination order sets circled, and the Post Discharge Diet Instruction and Activity Restrictions orders underlined](/images/post-acute-care-orders/page-04.png)

## 5. Examples by destination

Make sure to complete all discharge orders accordingly. Each destination order set has its own **Discharge Patient** disposition, and the matching sub-order-set is placed with it.

### Assisted living

Discharge Patient is set to **Assisted Living**, with **HOSP Assisted Living** placed alongside it.

![The HOSP DC Assisted Living Facility plan, with the Discharge Patient detail set to Assisted Living and an arrow pointing to HOSP Assisted Living](/images/post-acute-care-orders/page-05.png)

### Skilled nursing facility and home health

For a skilled nursing facility, Discharge Patient is set to **Skilled Nursing Facility** and **HOSP Skilled Nursing (SNF)** is placed. For home health, Discharge Patient is set to **Home with Home Health** and **HOSP Home Health** is placed.

![The HOSP discharge plan for a skilled nursing facility and the HOSP DC Home Health Care plan, each with the matching Discharge Patient detail and sub-order-set highlighted](/images/post-acute-care-orders/page-06.png)

### DME orders

For durable medical equipment, select **HOSP DME Orders** from the same section of the order set.

![The Admit/Transfer/Discharge/Status section with HOSP DME Orders highlighted](/images/post-acute-care-orders/page-07.png)

## 6. Review home medications

Open **Home Medications**, review the list and complete discharge reconciliation.

![The Home Medications section with a long medication list and the Discharge to Home link circled](/images/post-acute-care-orders/page-08.png)

## 7. Select patient education

Open **Patient Education**, then review and select the education that applies. Quick Suggestions are based on the problems for this visit.

![The Patient Education section with Quick Suggestions listed by problem](/images/post-acute-care-orders/page-09.png)

## 8. Add follow-up details

Open **Follow Up** and add follow-up details. Use the Quick Picks or search all providers.

When all of the above steps are completed, you should have green check marks on all red-asterisk sections. Then:

- Document the hospital course and patient discharge instructions.
- Create the **discharge summary** note and sign it.
- Create the **discharge med list** and sign it. This is required for discharge to any facility (SNF, assisted living, etc.).

![The Follow Up section with Quick Picks, a provider search box, and the Added Follow Ups area](/images/post-acute-care-orders/page-10.png)

## 9. Hospital course, patient instructions and notes

Select **Hospital Course** and **Patient Instructions** from the left menu to document them. Create the **Discharge Summary** (1) and **Discharge Med List** (2) notes from the Create Note list.

![The Discharge page with green check marks on completed sections, the Hospital Course and Patient Instructions links highlighted, and Discharge Summary and Discharge Med List numbered 1 and 2](/images/post-acute-care-orders/page-11.png)

<div class="takeaway">

Place **HOSP Discharge Orders**, choose the destination order set that matches where the patient is going, and finish every red-asterisk section. For facility discharges, don't forget to sign the discharge summary and the discharge med list.

</div>
